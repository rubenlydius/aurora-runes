# Aurora Runes

Write runes into the northern lights and discover the nine effects. 

https://rubenlydius.github.io/aurora-runes/



## Runes

- Sowilo: sun
- Thurisaz: thunder
- Laguz: water
- Kenaz: fire
- Hagalaz: hail
- Gebo: gift
- Isa: ice
- Dagaz: dawn
- Tiwaz: Tyr

## Original shader

The sky is a WGSL port of **"Auroras" by nimitz**:
https://www.shadertoy.com/view/XtGGRt
